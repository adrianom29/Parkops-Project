MANUAL DEPENDENCY/ENCAPSULATION REVIEW
Finding: protection of domain state is a convention, not a compiler guarantee.

- Intended rule: a booking moves only through StudentApplication.execute, after
  the status check and ReassignmentPolicy.executionBlocker.
- All classes are in the default package, so "package-private" hides nothing
  between layers.

  PeriodicScanner only reads them, but both receive mutable references.

ASSUMPTIONS ABOUT REFERENCED OBJECTS
- AttemptBudget holds only two ints and refers to no other object. One thread
  uses it; each AgentRunner.run creates its own.
- requireIdentifier: id is null or a java.lang.String, which is immutable, so
  length() and charAt() give the same answers throughout the call.

MANUAL ARGUMENT: AttemptBudget
Invariant established: the constructor returns only if 1 <= limit <= 6, and then
sets remaining = limit. Otherwise it throws and no object is returned.
Invariant preserved: consume() is the only method that writes remaining after
construction (the field is private; limit is final).
- remaining > 0 before: the guard is skipped and remaining is decreased by one.
  Postcondition remaining == old - 1 holds, and 0 <= old - 1 <= limit - 1.
- remaining == 0 before: throws IllegalStateException before any write.
By the invariant remaining is never negative, so these two cases are complete.
Frame: the normal case writes only remaining; the exceptional case writes no
existing state. remaining() and used() write nothing.

MANUAL ARGUMENT: requireIdentifier
First guard: || short-circuits, so null is never dereferenced and charAt(0) is
only reached for a non-empty string. A blank string is either empty or starts
with whitespace, which is outside 'A'..'Z', so isBlank() rejects nothing that the
contract accepts. Past the guard: 1 <= length <= 16 and charAt(0) in 'A'..'Z'.
Loop invariant: 1 <= i <= length, and every position k with 1 <= k < i is allowed.
- Initially: i = 1 and length >= 1; the range of k is empty.
- Preserved: if the body does not throw, position i is allowed, so the property
  holds for all k < i + 1. i < length before the step, so i + 1 <= length.
- On normal exit: i <= length and not i < length, so i = length. All positions
  1..length-1 are allowed, which is the normal precondition.
- On a throw in the loop: position i is a disallowed position, which is the
  witness for the exceptional precondition.
Variant: length - i is >= 0 by the invariant and decreases by 1 each iteration,
so the loop terminates.
Frame: only the local i and c are written; no existing state changes.
